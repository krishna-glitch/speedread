# SpeedRead

A simple app for practicing and improving reading speed.

## Features

- Start quick reading sessions
- Track words-per-minute (WPM)
- Clean, minimal interface for focused reading

## Getting Started

### Prerequisites

- Install the project dependencies (based on the tech stack used in this repo)

### Run Locally

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd speedread
   ```
2. Install dependencies:
   ```bash
   # Example commands (replace with your package manager)
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
